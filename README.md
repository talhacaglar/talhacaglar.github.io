# Talha Çağlar · Portfolio

[English](#english) · [Türkçe](#türkçe)

## English

Personal portfolio built with Next.js, React and Tailwind CSS, exported as a static website and published through GitHub Pages.

### Features

- Selected projects with implementation context and real application previews.
- Education, experience, certificates and contact links.
- Downloadable Turkish and English CVs.
- Responsive layout, keyboard navigation and reduced-motion support.

### Getting started

Use Node.js 24 to match the deployment workflow. Install the locked dependencies and run the development server.

```bash
git clone https://github.com/talhacaglar/talhacaglar.github.io.git
cd talhacaglar.github.io
npm ci
npm run dev
```

Live: [talhacaglar.github.io](https://talhacaglar.github.io/). Check with `npm run lint` and `npm run build`. A push to `main` triggers the Pages workflow, which publishes `out/`. The source of project content is `src/data/`.

## Türkçe

Next.js, React ve Tailwind CSS ile geliştirilen; statik olarak dışa aktarılıp GitHub Pages üzerinden yayınlanan kişisel portfolyo.

### Özellikler

- Uygulama bağlamı ve gerçek arayüz görüntüleriyle seçili projeler.
- Eğitim, deneyim, sertifikalar ve iletişim bağlantıları.
- İndirilebilir Türkçe ve İngilizce CV.
- Duyarlı yerleşim, klavye gezinmesi ve azaltılmış hareket desteği.

### Başlangıç

Yayın akışıyla aynı ortam için Node.js 24 kullanın. Kilitli bağımlılıkları kurup geliştirme sunucusunu başlatın.

```bash
git clone https://github.com/talhacaglar/talhacaglar.github.io.git
cd talhacaglar.github.io
npm ci
npm run dev
```

Canlı site: [talhacaglar.github.io](https://talhacaglar.github.io/). `npm run lint` ve `npm run build` ile denetleyin. `main` dalına push, `out/` klasörünü yayınlayan Pages akışını tetikler. Proje içeriklerinin kaynağı `src/data/` dizinidir.

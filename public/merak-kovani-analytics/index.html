Merak Kovani Analytics

Merak Kovani Analytics is a private, single-user tool run by the owner of the Merak Kovanı YouTube channel. It reads that channel's own YouTube statistics to plan future videos.

Privacy policy

Last updated: 13 October 2026

  • Data accessed: read-only YouTube Data API and YouTube Analytics API data (scopes youtube.readonly and yt-analytics.readonly) for the owner's own channel only: channel and video metadata, view counts, watch time, retention and aggregate audience reports.
  • Use: the data is used only to produce internal performance reports for the channel owner.
  • Storage: data and OAuth tokens are stored only on the owner's personal computer, with file permissions restricted to the owner. Nothing is uploaded to any server.
  • Sharing: data is not sold, shared or transferred to third parties, and is not used for advertising.
  • Revocation: access can be revoked at any time at myaccount.google.com/permissions; local copies can then be deleted.

Merak Kovani Analytics' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
